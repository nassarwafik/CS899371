📘 الحصة 6: المكتبة الرياضية (Math) والأعداد العشوائية

  • توليد عدد صحيح في مجال: rnd.Next(1, 7) (مثل رمية نرد 🎲).
  • توليد عدد عشري 0–1: rnd.NextDouble() ثم تحويله لمجال آخر (مثلاً 0–100).
  • استخدام دوال Math مع القيم العشوائية لحلول واقعية.

📘 الحصة 7: جملة الشرط (if – else if – else)

تعرّفنا في هذه الحصة على كيفية استخدام جملة if للتحقق من شروط منطقية وتنفيذ أوامر مختلفة حسب تحقق الشرط. كما تعلمنا استخدام else وelse if لمعالجة أكثر من حالة في البرنامج.

  • التحقق من شرط واحد: 
    if (x > 0) Console.WriteLine("موجب");
  • إضافة حالة بديلة باستخدام else: 
    if (x % 2 == 0) Console.WriteLine("زوجي");
else Console.WriteLine("فردي");
  • معالجة أكثر من شرط باستخدام else if: 
    if (mark >= 90) Console.WriteLine("ممتاز");
else if (mark >= 70) Console.WriteLine("جيد");
else Console.WriteLine("ضعيف");
